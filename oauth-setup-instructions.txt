================================================================
  GOOGLE, FACEBOOK & TIKTOK OAUTH SETUP INSTRUCTIONS FOR PEECHY
================================================================

Google, Facebook, and TikTok OAuth are all free to use.

----------------------------------------------------------------
  GOOGLE OAUTH
----------------------------------------------------------------

1. Go to: https://console.cloud.google.com

2. Create a new project (or select an existing one)

3. Left menu -> APIs & Services -> OAuth consent screen
   - Choose "External"
   - Fill in app name and your email
   - Save and continue

4. Left menu -> APIs & Services -> Credentials
   - Click "Create Credentials" -> "OAuth client ID"
   - Application type: Web application
   - Under "Authorized redirect URIs", add:

     LOCAL DEV:
       http://localhost:5173/api/auth/oauth/google/callback

     PRODUCTION (add when you deploy):
       https://yourdomain.com/api/auth/oauth/google/callback

   - Click "Create"

5. Copy the Client ID and Client Secret shown in the popup


----------------------------------------------------------------
  FACEBOOK OAUTH
----------------------------------------------------------------

1. Go to: https://developers.facebook.com

2. Click "My Apps" -> "Create App"
   - Choose "Authenticate and request data from users with Facebook Login"

3. Once created, go to Use Cases -> find "Facebook Login" -> Customize

4. Under "Valid OAuth redirect URIs", add:

     LOCAL DEV:
       http://localhost:5173/api/auth/oauth/facebook/callback

     PRODUCTION (add when you deploy):
       https://yourdomain.com/api/auth/oauth/facebook/callback

5. Left sidebar -> App settings -> Basic
   - App ID     = FACEBOOK_CLIENT_ID
   - App Secret = FACEBOOK_CLIENT_SECRET


----------------------------------------------------------------
  TIKTOK OAUTH (Login Kit)
----------------------------------------------------------------

1. Go to: https://developers.tiktok.com/apps

2. Click "Create an app"

3. In the app's dashboard, add the "Login Kit" product
   - Scopes needed: user.info.basic

4. Under "Redirect URI", add:

     LOCAL DEV:
       (TikTok generally requires HTTPS, even for testing — use a
       tunnel such as ngrok/cloudflared pointed at localhost:5173,
       e.g. https://<your-tunnel>.example.com/api/auth/oauth/tiktok/callback)

     PRODUCTION (add when you deploy):
       https://yourdomain.com/api/auth/oauth/tiktok/callback

5. Copy the "Client key" and "Client secret" from the app's Basic
   Information page.

NOTE: TikTok's Login Kit does not return the user's email address —
Peechy signs these users up with a synthetic placeholder email
(tiktok_<open_id>@oauth.peechy.app) and their TikTok display name.


----------------------------------------------------------------
  ADD TO YOUR .env FILE
----------------------------------------------------------------

GOOGLE_CLIENT_ID=your_google_client_id_here
GOOGLE_CLIENT_SECRET=your_google_client_secret_here
FACEBOOK_CLIENT_ID=your_facebook_app_id_here
FACEBOOK_CLIENT_SECRET=your_facebook_app_secret_here
TIKTOK_CLIENT_KEY=your_tiktok_client_key_here
TIKTOK_CLIENT_SECRET=your_tiktok_client_secret_here


----------------------------------------------------------------
  NOTES
----------------------------------------------------------------

- For local development, redirect URIs must use http://localhost:5173
  (or whichever port your dev server runs on, check terminal output)
  — except TikTok, which requires an HTTPS redirect URI even in dev.

- When deploying to production, add your https:// URLs in the
  Google Cloud Console, Facebook App Dashboard, and TikTok Developer
  Portal.

- The app will not work until the env vars are set and the
  redirect URIs are registered in all three dashboards.
